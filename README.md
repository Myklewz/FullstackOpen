## 🚀 How to view the projects
Each part is organized into its own directory. To run a specific project:

1. Navigate to the folder (e.g., `cd part1` -> `cd unicafe`)
2. Install dependencies: `npm install`
3. Run the application: `npm start` (or `npm run dev` for Vite projects)
